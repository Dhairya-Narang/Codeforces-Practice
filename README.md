## 🗂️ Repository layout

- **`Level 800/`** — practice problems around the 800 rating level.
- **`CodeForces DIv3/`** — solutions from Div. 3 rounds.
- **`CodeForces Div4/`** — solutions from Div. 4 rounds.
- **`CodeForces Div2/`** — Div. 2 and Educational rounds; currently contains Educational Codeforces Round 195.

Contest solutions are grouped into round folders. Files such as `ProbA.c` and `ProbB.c` correspond to problem letters. Folder capitalization follows the existing names in the repository.

## ▶️ Compile and run

Each solution is an independent program. From the repository root, compile one with GCC:

```sh
gcc -std=c11 "CodeForces Div4/Codeforces Round 806 (Div. 4)/ProbA.c" -o solution
./solution
```

The program reads input from standard input, as specified by its Codeforces problem. Replace the source path with the file you want to run. On Windows, use `solution.exe` as the output filename and run it with `solution.exe`.
